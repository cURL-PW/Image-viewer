# デバッグログとクラウド同期フォルダの診断

iCloud などの同期フォルダで、意図しないダウンロードが続くときの調べ方です。

## 未ダウンロードの判定のしくみ

判定は **Windows のファイル属性** で行います。iCloud の未ダウンロードファイルには
`OFFLINE` と `RECALL_ON_DATA_ACCESS` が立っているので、これを見れば確実に区別できます。
属性の列挙 (`Get-ChildItem`) はファイルのデータを読まないため、調べる過程でダウンロードは起きません。
**1 枚も落とさずに** 未ダウンロードを特定できるので、ローカルにある写真だけは
今までどおりサムネイル生成もタグ付けも進みます。

この一覧は「1 枚ずつ確実に弾く」ためのもので、これがあっても
**読み込みが遅い状態が続いたら全体を打ち切る**回路遮断器は残したままにします。
列挙に成功していても、パスの食い違いなどで取りこぼす可能性があるためです。
遮断器は OS の実装に依存しないので、どんな同期クライアントでも最後はここで止まります。
一度クラウドと判定したフォルダは記憶するので、次に開くときは最初から止めた状態で始まります。

そのため状態は 2 つあります。設定画面の診断にも別々に出ます。

| 状態 | 意味 |
| --- | --- |
| クラウドフォルダ判定 | 未ダウンロードの写真がある (案内バーを出す条件) |
| 自動読み込み | サムネイル生成とタグ付けを実際に止めているか |

判定の内訳は **設定画面の「クラウド同期フォルダの診断」** で確認できます。
どの経路 (走査の `stat` / サムネイル / 表示) が何ミリ秒かかっているか、
未ダウンロード判定が当たっているかが並びます。

## デバッグログ

それでもダウンロードが続く場合に備えて、**ファイルに触れた操作をすべて記録**できます。
ファイルパスが残るので**既定ではオフ**です。設定画面の診断セクションでオンにしてから、
もう一度アプリを起動して症状を再現してください。

- **デバッグログを記録する** — 記録の入り切り。環境変数 `IMAGE_VIEWER_DEBUG_LOG=1` で起動時から強制的に有効、`=0` で無効にできます
- **ログフォルダを開く** — `%APPDATA%\image-viewer\logs\debug.log`
- **直近をコピー** — 末尾 300 行をクリップボードへ (共有する前に、ファイル名に人に見せたくないものが無いか確認してください)

同じ行が延々と続くもの (走査の 1 ファイルごとの記録など) は件数ごとにまとめます。
ただし 200ms を超えた `stat` だけは 1 件ずつ残します。クラウドの実体取得はそこに出ます。

1 行が 1 操作で、タブ区切りです。

```
2026-08-25T12:34:56.789Z  walk-stat     allowed    12ms  Photos/IMG_8582.HEIC
2026-08-25T12:34:57.001Z  thumb-gen     blocked     0ms  Photos/IMG_8583.HEIC  未ダウンロード
2026-08-25T12:35:02.100Z  open-image    forced   5210ms  Photos/IMG_8584.HEIC
2026-08-25T12:35:02.400Z  watch-change       -       -   Photos/IMG_8584.HEIC
```

見るのは 2 点です。

- **数秒かかっている行の種別** — そこがダウンロードを起こしている経路です
- **`guard-index` / `ps-scan` の行** — 未ダウンロードの一覧が作れているか、
  その一覧のパスがアプリ側のパスと噛み合っているか

動作が重いときは、次の行も手がかりになります。

- **`main-busy`** — 本体の処理がその時間止まっていました。その間は画面の更新も、ブラウザからの取り込みも待たされます。直前の行が原因の候補です
- **`ipc-slow`** — 画面からの問い合わせ (補足欄が名前) が、本体を 100ms 以上止めていました
- **`browser-import`** — ブラウザからの取り込み 1 枚にかかった時間 (前の取り込みの順番待ちを含む)

アプリ側の行が出ていないのにダウンロードが続くなら、発火元はアプリの外
(iCloud クライアント自身の同期) ということになります。
ログは 8MB で 1 世代だけ退避します (`debug.log.1`)。
